# Личный кабинет ПК-клуба

Мобильное приложение на Flutter для клиентов компьютерного клуба. Приложение позволяет авторизоваться, смотреть новости, бронировать игровые места, оформлять заказы из каталога и работать с историей активностей в клубе.

## Что уже реализовано

### Пользовательские сценарии
- Авторизация по телефону и паролю.
- Регистрация нового клиента.
- Сохранение пользовательской сессии между запусками приложения.
- Просмотр новостей клуба.
- Просмотр каталога товаров и услуг.
- Корзина и оформление заказа.
- Бронирование ПК через список и через карту зала.
- Просмотр активных бронирований.
- Просмотр истории заказов.
- Просмотр истории игровых сессий.
- Просмотр профиля клиента и баланса.
- Переключение светлой и темной темы.
- Экран поддержки.

### Что добавлено и обновлено в проекте
- Переведена клиентская часть на JWT-авторизацию.
- Сессия теперь восстанавливается по токену из secure storage при старте приложения.
- Убрана зависимость ключевых экранов от передачи `clientId` в клиентских запросах.
- API-слой обновлен под более безопасный серверный контракт.
- Добавлена поддержка единого формата ошибок сервера через поля `message` и `code`.
- Добавлена более гибкая обработка ответов API, включая обертки вида `data` и `result`.
- Обновлен поток регистрации и входа под новый сервер.
- Обновлены запросы профиля, заказов, бронирований и истории сессий под модель "текущий пользователь".
- Карта зала теперь опирается на реальные доступные ПК с сервера, а не только на локальные мок-данные.
- Экран бронирования корректно сопоставляет выбранный ПК с реальным списком доступных машин.
- Обновлены клиентские модели под новые серверные поля и статусы.
- Базовый URL API переведен на версионированный маршрут `/api/v1`.

## Основные экраны

### Аутентификация
- `LoginScreen` — вход в аккаунт.
- `RegisterScreen` — регистрация нового пользователя.

### Основная навигация
- `MainScreen` — нижняя навигация по разделам приложения.
- `NewsScreen` — новости клуба.
- `CatalogScreen` — каталог услуг и товаров.
- `ClientProfileScreen` — профиль пользователя.

### Бронирование
- `BookingScreen` — выбор ПК, даты и времени бронирования.
- `ClubMapScreen` — карта зала с выбором места.
- `ActiveBookingsScreen` — список бронирований пользователя.

### Заказы и история
- `CartScreen` — корзина и оформление заказа.
- `OrderHistoryScreen` — история заказов.
- `SessionHistoryScreen` — история игровых сессий.

### Дополнительно
- `SupportScreen` — форма поддержки.
- `FAQScreen` — экран FAQ.

## Техническая часть

### Стек
- Flutter
- Provider
- HTTP
- Hive
- Flutter Secure Storage
- Intl

### Архитектура
- `lib/services` — API, локальное хранение, корзина.
- `lib/models` — модели данных приложения.
- `lib/screens` — экраны пользовательского интерфейса.
- `lib/providers` — провайдеры состояния.
- `lib/theme` — тема и стили интерфейса.
- `lib/utils` — обработка ошибок и валидация.

### Работа с API
- Вся интеграция с сервером сосредоточена в `ClientApiService`.
- Поддерживается авторизация через `Bearer` токен.
- Реализована централизованная обработка серверных ошибок.
- Добавлена совместимость с новыми и переходными форматами ответов сервера.

## Что важно проверить после изменений на сервере

После обновления backend особенно полезно вручную проверить:
- регистрацию нового пользователя;
- вход и восстановление сессии;
- загрузку профиля текущего клиента;
- создание бронирования;
- отображение карты зала;
- оформление заказа из корзины;
- загрузку истории заказов и игровых сессий.

## Планы на дальнейшее развитие

### Ближайшие шаги
- Поддержка `refresh token` и автоматического обновления access token.
- Автоматический logout и понятная обработка `401 Unauthorized`.
- Точная подстройка клиента под финальный контракт backend без fallback-маршрутов.
- Отмена активного бронирования из приложения.
- Улучшение отображения серверных статусов заказов и броней.

### Улучшение UX
- Push-уведомления о бронировании, заказах и начале игровой сессии.
- Автообновление карты зала в реальном времени.
- Более подробная карточка ПК: зона, характеристики, статус.
- Экран активной игровой сессии.
- Экран оплаты и пополнения баланса.

### Улучшение качества проекта
- Widget- и integration-тесты для авторизации, бронирований и заказов.
- Покрытие тестами критичных серверных ошибок.
- Централизация роутинга приложения.
- Вынос API DTO и маппинга в отдельный слой.
- Улучшение офлайн-поведения и кеширования.

## Запуск проекта

1. Установите Flutter SDK.
2. Выполните:

```bash
flutter pub get
```

3. Запустите приложение:

```bash
flutter run
```

## Проверка качества

Для проверки проекта можно использовать:

```bash
flutter analyze
flutter test
```

## Примечание

Проект находится в активной разработке. После изменений backend-контракта мобильное приложение регулярно подстраивается под новые маршруты, форматы ответов и правила авторизации.
