# Личный кабинет ПК‑клуба (Flutter Application)

Мобильное приложение для клиентов компьютерного клуба, позволяющее управлять своим профилем, просматривать новости, каталог услуг и бронировать игровые места.

## Что реализовано на данный момент

### 📱 Интерфейс и экраны
*   **Экран входа (`LoginScreen`)**: Полноценная авторизация по номеру телефона и паролю с сохранением сессии.
*   **Экран регистрации (`RegisterScreen`)**: Создание нового аккаунта.
*   **Главный экран (`MainScreen`)**: Удобная нижняя навигация (Новости, Каталог, Профиль).
*   **Новости (`NewsScreen`)**: Лента событий с индикаторами загрузки и обработкой ошибок.
*   **Каталог (`CatalogScreen`)**: 
    *   Быстрые действия: кнопка бронирования и переход на интерактивную карту.
    *   Список товаров и услуг с автоматическим определением типа (бронь/покупка).
    *   Интерактивная корзина с бейджем количества товаров.
    *   **Фильтрация по категориям** и **поиск** товаров.
*   **Интерактивная карта (`ClubMapScreen`)**: Визуальный выбор ПК на схеме зала с отображением статуса (свободно/занято).
*   **Корзина (`CartScreen`)**: Управление покупками, расчет суммы и подтверждение заказа.
*   **Профиль пользователя (`ClientProfileScreen`)**: 
    *   Градиентный виджет баланса с возможностью пополнения.
    *   **Переключение Тем**: Поддержка Светлой и Темной (игровой) тем.
    *   История бронирований, заказов и игровых сессий.
*   **Мои бронирования (`ActiveBookingsScreen`)**: Список активных записей.
*   **История заказов (`OrderHistoryScreen`)**: Список покупок товаров и еды.
*   **История сессий (`SessionHistoryScreen`)**: Архив игрового времени.
*   **Поддержка (`SupportScreen`)**: Форма обратной связи и контакты.

### ⚙️ Техническая часть
*   **API Интеграция**: Сервис `ClientApiService` полностью подключен к бэкенду. Реализованы все методы: логин, регистрация, получение данных, бронирование и оформление заказов.
*   **Управление состоянием**: `CartService` для синхронизации корзины.
*   **Локализация**: Полная поддержка русского языка (`intl`).
*   **Локальное хранение**: `Hive` для кэширования профиля и настроек.

## 🚧 Что не успели сделать (Планы по развитию)

Ниже перечислены функции, которые запланированы для следующих итераций разработки:

### 1. Безопасность и Сессии
*   **JWT Refresh Tokens**: Сейчас используется простая авторизация. Необходимо внедрить механизм обновления токенов для безопасности.
*   **Смена пароля**: Добавить функционал изменения пароля и восстановления через SMS/Email.

### 2. Уведомления и Реальное время
*   **Push-уведомления**: Оповещения о начале бронирования, окончании игрового времени (за 10-15 минут) и новых акциях.
*   **WebSockets для карты**: Чтобы статус компьютеров на карте (`ClubMapScreen`) обновлялся мгновенно, когда кто-то другой занимает место.

### 3. Финансы и Заказы
*   **Платежный шлюз**: Интеграция с реальными API (СБП, ЮKassa, Stripe) для пополнения баланса внутри приложения.
*   **Детальный статус заказа**: Отслеживание процесса приготовления еды (принято -> готовится -> доставляется).

### 4. Геймификация и Лояльность
*   **Система достижений**: Награды за количество проведенных часов или ночные сессии.
*   **Бонусный баланс**: Отдельный счет для кэшбэка и промокодов.

### 5. Прочее
*   **Редактирование профиля**: Возможность смены имени, email и загрузки аватара.
*   **FAQ**: Раздел с ответами на часто задаваемые вопросы.
